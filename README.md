# BT115 TV Helper

تطبيق Android TV يبحث دوريًا عن أي جهاز Bluetooth يكون اسمُه المعلن متضمنًا `BT115` بأي صيغة، مثل `BT115-002` أو `Remote-BT115-Pro`. يطلب الاقتران عند العثور على جهاز غير مقترن، ثم يترك Android Bluetooth stack يدير اتصال الجهاز المقترن وإعادة الاتصال به.

## البناء من GitHub

ارفع محتويات المشروع إلى مستودع GitHub على الفرع `main`، ثم افتح **Actions** وانتظر تشغيل `Build Android TV APK`. نزّل Artifact باسم `bt115-tv-helper-debug-apk`. يمكن أيضًا تشغيله يدويًا من **Actions → Build Android TV APK → Run workflow**. الناتج APK تجريبي موقّع بمفتاح debug.

## التشغيل

افتح التطبيق واضغط «ابدأ الآن»، ثم اسمح بإذني Bluetooth Scan وBluetooth Connect. عند العثور على جهاز غير مقترن، يطلب التطبيق الاقتران عبر Android؛ قد يحتاج المستخدم إلى الموافقة على نافذة النظام أو إدخال PIN. فعّل «بدء البحث مع تشغيل النظام» بعد منح الأذونات لتشغيل خدمة المراقبة عند الإقلاع. تتطلب المراقبة المستمرة خدمة foreground وقد يظهر إشعار مستمر. يمكن لقيود firmware/إدارة الطاقة لدى الشركة المصنّعة إيقاف التشغيل التلقائي أو الخدمة؛ لا يمكن لأي APK عادي ضمان تجاوز هذه القيود.

## إبقاء الاتصال وإعادة الاتصال

المشروع لا ينفذ أوامر root/ADB ولا يغير حالة اتصال وهمية. بعد الاقتران يحفظ Android عادةً علاقة الاقتران ويتولى إعادة اتصال HID عند توفر الريموت. يتوقف التطبيق عن البحث عند تلقي حدث اتصال فعلي لاسم BT115. وبعد إعلان الانقطاع ينتظر ثانية واحدة ثم يستأنف اكتشاف الأجهزة، كما يراقب عودة Bluetooth إذا أوقفه النظام أو المستخدم. هذا يسرّع استجابة خدمة المراقبة، لكنه لا يجعل Android يعتبر الرابط قائمًا أثناء الانقطاع ولا يغيّر مؤقتات الوصلة اللاسلكية.

لا تستطيع واجهات Android العامة للتطبيقات العادية إجبار ريموت HID على البقاء متصلًا، أو إرسال keep-alive/تقارير HID نيابة عنه، أو تغيير GATT connection priority وBluetooth link supervision timeout. إذا كان الريموت نفسه ينام أو يطفئ Bluetooth أو يقطع الرابط بسبب البطارية/firmware، سيظل Android قادرًا على إعلان الانقطاع. تحسين ذلك يحتاج دعمًا من firmware الريموت أو Bluetooth stack الخاص بالجهاز، وليس مجرد تطبيق مراقبة.

## الملفات

`MainActivity.java` تعرض الواجهة وتطلب أذونات Bluetooth. `BluetoothWorkerService.java` يبحث بالاسم الجزئي `BT115`، يطلب الاقتران، يتابع أحداث الاتصال الحقيقية، ويتوقف عن البحث أثناء الاتصال أو الاقتران. `BootReceiver.java` يقرأ خيار بدء المراقبة مع الإقلاع. `.github/workflows/android.yml` يبني APK ويرفعه كـ Artifact.

## متطلبات البناء

Android Gradle Plugin 8.7.3، Gradle 8.9، JDK 17، وAndroid SDK Platform 35 / Build Tools 35.0.0. الحد الأدنى Android 8.0، والهدف Android 14.
